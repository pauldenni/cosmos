# PM Calibration Template — For Individual Contributors

**Audience: anyone calibrating themselves.** Managers assessing someone else use [[reference/org/pm-calibration-template-manager]].

Self-calibration against the [[reference/org/pm-career-ladder|TPM Career Ladder]]. Copy this file to `journal/calibrations/MMDDYY-self-calibration.md` and fill in, or run `/prep calibration self`.

This mirrors the manager template axis for axis, on purpose. Your read and your manager's read should be directly comparable — where they diverge is the most useful conversation you can have.

The same evidence rule applies to you: if you can't cite evidence, you don't have a rating yet. **Insufficient Evidence** is a valid outcome and usually means one of two things — you haven't had the opportunity yet, or you have and nobody saw it. Those are different problems with different fixes.

## Five-Axis Self-Assessment

Rate yourself against the **current level's expectations** — not the next level, and not against the strongest person you know. Valid outcomes: **Below · At · Above · Insufficient Evidence**.

| Axis | Below · At · Above · Insufficient Evidence | Evidence |
|---|---|---|
| **Scope** — what I own | | |
| **Autonomy** — how independently I operate | | |
| **Influence** — reach of my impact | | |
| **Technical Depth** — sophistication of my technical judgment | | |
| **People Impact** — my lever on others | | |

**Pattern check:** Three or more *Above* means you are likely already operating at the next level — the work now is building the case, not building the skill. Three or more *Below* means find the root cause before you self-flagellate: wrong level, wrong scope, missing support, or something outside work. Two or more *Insufficient Evidence* means **this calibration isn't finished** — go get the evidence, or go get the opportunity that would produce it.

**Calibration honesty check:** Rating yourself *At* on everything is the most common failure mode of this exercise. If every axis came out the same, you probably rated your self-image rather than your evidence.

**Gap type.** For each criterion you can't evidence, name which kind of gap it is:

| Gap | Means | Fix |
|---|---|---|
| **Capability** | I can't do this yet | Build the skill — coaching, training, a smaller rep first |
| **Scope** | I could, but haven't been given the surface | Ask for the opportunity, explicitly, with a named target |
| **Visibility** | I have done this and it wasn't seen | Fix the reporting path — this is the cheapest gap to close and the most commonly misdiagnosed as capability |
