# PM Growth Plan Template

**Audience: anyone planning their own next cycle.** Lighter than a full calibration and meant to run quarterly. A calibration tells you where you stand; this decides what you do about it.

Copy to `journal/calibrations/MMDDYY-growth-plan.md` and fill in.

Run this after a calibration if you have one — [[reference/org/pm-calibration-template-self]] produces the gap list this plan acts on. Without one, start from the last thing your manager told you to work on.
