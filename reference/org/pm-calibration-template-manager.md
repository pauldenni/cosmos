# PM Calibration Template

Calibration check against the [[reference/org/pm-career-ladder|TPM Career Ladder]]. Copy this file to `journal/calibrations/MMDDYY-<person>-calibration.md` and fill in.

The structure forces evidence-based judgment on every dimension. If you can't supply evidence, you don't have a rating yet — and that itself is a finding. Use **Insufficient Evidence** as a valid outcome whenever the cosmos record (or your direct read) doesn't support a defensible rating — it's a calibration *data* gap to fix, not a person gap to paper over.

## Five-Axis Assessment

Rate each axis against the **current level's expectations**. Evidence required for every rating — vibes don't calibrate. Valid outcomes: **Below · At · Above · Insufficient Evidence**. Don't guess to fill a cell.

| Axis | Below · At · Above · Insufficient Evidence | Evidence |
|---|---|---|
| **Scope** — what they own | | |
| **Autonomy** — how independently they operate | | |
| **Influence** — reach of impact | | |
| **Technical Depth** — sophistication of technical judgment | | |
| **People Impact** — lever on others | | |

**Pattern check:** If three or more axes are *Above*, this person is likely operating at the next level — investigate promotion readiness. If three or more are *Below*, this is a calibration concern — investigate root cause (wrong level, wrong scope, performance issue, life circumstance). If two or more are *Insufficient Evidence*, **the calibration isn't done yet** — close the data gap (1:1 history, peer input, direct observation) before drawing conclusions.
