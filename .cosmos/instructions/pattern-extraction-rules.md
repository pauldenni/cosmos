# Pattern Extraction Rules

The purpose of pattern extraction is to identify:
- recurring operational signals
- persistent organizational themes
- dependency concentration
- emerging execution risks
- leadership-relevant operational movement

# Core Principle

cosmos should optimize for:

signal persistence over time

NOT:
- isolated events
- one-off mentions
- tactical implementation detail

# High-Signal Patterns

Patterns become meaningful when they:
- appear repeatedly
- impact multiple teams
- affect delivery confidence
- require leadership coordination
- create recurring escalations
- influence rollout sequencing
- appear across multiple update sources

# Pattern Extraction Priorities

Prioritize extracting:
1. recurring blockers
2. dependency concentration
3. leadership escalation themes
4. delivery confidence changes
5. organizational friction
6. cross-functional coordination failures
7. operational drift
8. ownership ambiguity
9. milestone instability
