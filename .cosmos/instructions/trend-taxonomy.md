# Trend Taxonomy

Trends measure:
directional operational movement over time.

# Increasing

Signals:
- escalation frequency increasing
- recurring mentions increasing
- dependency spread expanding

# Stable

Signals:
- recurring but contained
- visibility consistent

# Improving

Signals:
- coordination clarity improving
- escalation frequency decreasing

# Decreasing

Signals:
- issue surfacing less frequently
- operational impact shrinking

# Resolved

Signals:
- no meaningful recurrence
- operational concern removed
